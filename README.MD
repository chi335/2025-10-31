# 🧩 Git & GitHub 학습 가이드

> 깃(Git)과 깃허브(GitHub)를 활용하여 **버전 관리, 협업, 개발 환경 구축**을 익히는 실습 중심 가이드입니다.

---

## 🪄 1️⃣ Git 기본 개념 및 버전 관리 (01~03)

| 구분 | 주제 | 핵심 내용 |
|:----:|:-----|:----------|
| **01** | **깃 시작하기** | - 깃의 3대 역할: 📂 **버전 관리**, ☁️ **백업**, 👥 **협업**<br>- 깃 설치 및 환경 설정 (리눅스 명령, Vim 사용법 등) |
| **02** | **깃으로 버전 관리하기** | - 저장소 생성: `git init`<br>- 스테이징 & 커밋으로 버전 생성<br>- 되돌리기: `git revert`, `git reset` |
| **03** | **깃과 브랜치** | - 독립적인 작업 흐름을 위한 **브랜치(Branch)** 이해<br>- 브랜치 생성/전환/확인<br>- 병합: **Merge**, **Rebase**, **Cherry-pick** |

---

## 🌐 2️⃣ GitHub 활용 및 협업 (04~06)

| 구분 | 주제 | 핵심 내용 |
|:----:|:-----|:----------|
| **04** | **깃허브 시작하기** | - 원격 저장소 개념 이해<br>- 지역 저장소 연결: `git remote`<br>- 푸시/풀 동기화<br>- **SSH 원격 접속 설정** |
| **05** | **깃허브로 협업하기** | - 원격 저장소 복제: `git clone`<br>- 원격 브랜치 정보 가져오기<br>- **Pull Request (PR)** 생성 및 병합 실습 |
| **06** | **깃허브에서 소통하기** | - 깃허브 프로필 관리<br>- **README 작성** 및 **Markdown 문법** 학습<br>- 오픈소스 기여 (번역, 문서화, 버그 제보 등) |

---

## 💻 3️⃣ 개발 환경 실습 및 최신 기능 (07~NEW)

| 구분 | 주제 | 핵심 내용 |
|:----:|:-----|:----------|
| **07** | **VS Code로 깃/깃허브 관리하기** | - VS Code **소스 제어(GUI)** 활용<br>- 커맨드 없이 저장소 생성, 커밋, 브랜치 관리<br>- 깃허브 연결 및 동기화 |
| **08** | **이력서 사이트 & 블로그 만들기** | - **GitHub Pages**로 HTML/CSS 이력서 웹사이트 제작<br>- **Jekyll 블로그** 구축 및 포스트 작성 |
| **NEW** | **깃허브 최신 기능** | - **클라우드 개발 환경**: Codespaces, GitHub Dev (`github.dev`)<br>- **AI 코드 추천 서비스**: GitHub Copilot |

## 💡 참고 & 팁
- **작업 전 확인:** `git status`  
- **이전 버전 확인:** `git log --oneline --graph`  
- **새 브랜치 생성:** `git branch feature/login`  
- **PR 생성 후 리뷰 요청**을 통해 협업 품질 향상
